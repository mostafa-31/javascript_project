# 3D Calculator

This project is a simple 3D calculator implemented using HTML, CSS, and JavaScript. It allows users to perform basic mathematical operations and some advanced calculations like square roots, logarithms, and exponentials.

## Features
- Basic arithmetic operations: addition, subtraction, multiplication, division.
- Advanced operations: square root, logarithm with user-defined base, exponentiation with e.
- Interactive buttons with sound effects.
- Intuitive and responsive UI design.

## File Structure
- `index.html`: Contains the main structure and layout of the calculator.
- `styles.css`: Contains the styling for the calculator.
- `script.js`: Contains the functionality for the calculator, including event handlers for button clicks and the logic for mathematical calculations.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/mostafa-31/javascript_project.git
   ```
2. Navigate to the project directory:
   ```bash
   cd javascript_project
   ```
3. Open `index.html` in your web browser to start using the calculator.

## Usage
- Click on the calculator buttons to input numbers and operators.
- Use the `AC` button to clear all inputs and start a new calculation.
- Use the `CLR` button to delete the last input.
- Use the `=` button to calculate the result.
